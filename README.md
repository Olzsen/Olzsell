# FunPay Telegram

Бесплатная Telegram-платформа для управления собственным аккаунтом FunPay.

> Проект находится на ранней стадии разработки. Интерфейс, документация и сообщения пользователю — на русском языке.

## Идея

Один публичный Telegram-бот обслуживает многих пользователей бесплатно. Регистрация с логином и паролем не нужна: Telegram ID используется только для определения владельца данных. Каждый пользователь подключает **свой** аккаунт FunPay; данные, настройки, плагины и сессии строго разделяются между пользователями. Платных тарифов и внутреннего баланса/оплаты за функции не будет.

## Возможности в планах

- Управление лотами, заказами и сообщениями FunPay.
- Telegram-панель на inline-кнопках.
- Обновление существующих сообщений вместо засорения чата новыми.
- Карточки, псевдотаблицы, пагинация, фильтры и контекстные действия.
- Плагины с событиями, настройками, командами и жизненным циклом.
- Поддержка нескольких FunPay-профилей одного Telegram-пользователя — опционально.
- Изоляция данных пользователей и бесплатное использование общей публичной инсталляции.
- SQLite по умолчанию; PostgreSQL для крупных установок.
- Docker и запуск на Windows/Linux.

## Telegram-интерфейс

Используем возможности Telegram Bot API: HTML-разметку, inline-клавиатуры, callback-кнопки, редактирование текста/подписей сообщений, уведомления и пагинацию.

Telegram не поддерживает произвольные HTML-таблицы внутри сообщений. Табличные представления будут формироваться из моноширинного текста и адаптивных карточек. Обновление баланса будет выполняться редактированием сообщения после получения свежих данных от FunPay; частота обновления будет ограничена, чтобы не упираться в лимиты Telegram и FunPay.

## Безопасность

- Telegram ID — технический идентификатор пользователя, отдельная регистрация не требуется.
- Сессии FunPay должны храниться раздельно для каждого Telegram ID и шифроваться ключом сервера.
- Не отправляйте токены, cookies и пароли в Issues, логи или публичные чаты.
- Сторонние Python-плагины могут выполнять произвольный код. Установка плагина требует доверия к автору; в дальнейшем будут добавлены разрешения и изоляция.
- Опасные действия (массовое удаление/изменение лотов) должны иметь подтверждение и журнал.

## Быстрый старт

Пока недоступен: сначала будет подготовлен минимальный рабочий каркас и инструкция запуска.

```

  funpay/       клиент и адаптер FunPay

tests/
```
